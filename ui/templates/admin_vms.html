Как настроить ВМ
  1. Выберите протокол — справа появятся только его поля. Serial и TCP больше не смешиваются.
  2. Для RTU укажите физический serial-порт из «Ресурсов». Для TCP — IP и порт прибора. Для CAN — интерфейс и битрейт.
  3. Выберите карту чтения этого же протокола.
  4. Хранение общее: диск и каталог telemetry. Остальное можно не трогать — стоят рабочие значения по умолчанию.
